# Agent Instructions

너는 이 프로젝트를 완성시키는 주체야.

.venv의 가상환경에서 진행하고 필요한 모듈이 있다면 가상환경에서 uv로 모듈을 저장하고, pyproject.toml을 작성해.

이 md파일과 프로젝트를 전부 잘 읽고 파악해. **.py** 파일들에는 주석을 달아놨으니 잘 읽어보고 app.py만 완성시키면 되. 필요하면 코드를 추가해도 되. 하지만 기존 코드나 **.env**에 잇는 사항을 수정하지 않는 선에서 무엇을 어떻게 추가하든 마음대로 해도 좋아.

SOLID 원칙을 지켜(무조건 지킬 필요는 없지만 가능하다면, 성능에 방향을 주지 않는 선에서 해줘), 그리고 코드는 최대 200줄 이내로 작성해줘.(마찬가지로 꼭 지킬 필요는 없지만 클린 코드와 가독성을 위해서 특수한 상황이 아니라면 지켜줘)

### 수행 과제:
1. 현재 wvr이라는 파일에서 모든 model의 모든 table을 **sqlite3**로 사용할 수 있도록 **.db** 파일에 저장하는 작업을 해줘. 모든 **.db**는 "db" 디렉터리에 저장해주고.
2. 그리고 그렇게 저장된 모든 **.db**를 **sqlite3**를 사용해서 인덱싱 가능한 읽기 전용 ORM 모델을 **models** 디렉터리에 생성해줘. ORM 모델이 잘 생성된다면, **repositories** 디렉터리에 ORM에 연계가능한 repository 모듈을 생성해줘.
3. 그리고 이러한 기능이 잘 작동하는지 테스트할 수 있도록, **tests** 디렉터리에 테스트 코드를 작성해줘. **__handle_exception**를 모든 테스트 메소드에 붙여줬으면 해.
